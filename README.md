# Hey Lil Bird V2

**Public name:** hey lil bird  
**Tagline:** Here for your assistance. Just ask, human.

This V2 is a substantially expanded static prototype based on the project blueprint.

Included:
- Public-facing Hey Lil Bird identity
- Psychology / neuroscience / mental-health learning architecture
- Search-friendly standalone-style sections and metadata
- Psychology foundation article
- Neuroscience foundation article
- Mental-health education section
- Research-methods / "How we know" section
- Stories and reflection
- Books / research / cases / glossary library structure
- Pre-chat needs selection
- Communication-style selection
- Optional age / nickname / gender / country fields
- Skip-and-talk path
- Lil Bird chat interface
- Basic scripted safety responses
- Privacy-by-design messaging
- Mobile responsive design
- Reduced-motion accessibility support

Important:
This remains a prototype. The chat is NOT a real AI service and does not send messages to a server. No production database, authentication, moderation, crisis routing, verified resource database, secure storage, real AI model, expert review, or legal/compliance system is included yet.
